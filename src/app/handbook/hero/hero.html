Complete Study Handbook

Angular, from first principles to interview-ready

Every core Angular concept explained plainly, then reinforced with real production code and the questions interviewers actually ask. Written against Angular 21 with the modern APIs — signals, standalone, inject(), native control flow — and clear flags wherever the older syntax still shows up in real codebases.

How to read this

The handbook runs in three arcs: Foundations (Modules 1–5) get you writing components; Building blocks (6–9) cover forms, routing, and state; Advanced & interview (10–16) close the loop with the topics that separate juniors from seniors. The final section is a bank of 100+ interview questions with collapsible answers — read the question, try to answer it, then expand to check.

Modern vs legacy

Angular is mid-transition. This guide teaches the modern way and marks it modern, but shows the legacy syntax too — because real codebases (and interviewers) mix both. Knowing the difference is itself a strong signal.
