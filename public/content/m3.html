@switch (state) {
  @case ('PENDING')  { <span>Pending</span> }
  @case ('ACCEPTED') { <span>Accepted</span> }
  @default           { <span>{{ state }}</span> }
}

@let total = price() * qty();   // name a value once, reuse in template
  • track is mandatory in @for — it identifies each item so Angular reuses DOM nodes instead of re-rendering the whole list. Use a stable id, or track $index.
  • Implicit vars in @for: $index, $first, $last, $even, $odd, $count.
Legacy

Older code uses *ngIf, *ngFor, *ngSwitch (structural directives with *). The @-blocks are faster and are the default now. Recognize both; write the new ones.

Directives: three kinds

KindDoesExamples
Structuraladd/remove elements@if/@for, legacy *ngIf
Attributechange appearance/behaviour[class.x], custom [clickOutside]
Componenta directive with a templateevery component
@Directive({
  selector: '[clickOutside]',                       // attribute selector, in [brackets]
  host: { '(document:click)': 'onClick($event.target)' }, // host object, NOT @HostListener
})
export class ClickOutsideDirective {
  private el = inject(ElementRef);
  clickOutside = output<void>();
  onClick(t: EventTarget | null) { /* emit if outside */ }
}
Convention

Modern Angular: use inject() not constructor injection, output() not @Output, and the host object not @HostListener/@HostBinding.
