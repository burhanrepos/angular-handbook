Angular is a framework for building web apps. Instead of manually updating the DOM, you declare what the UI should look like and Angular keeps the screen in sync with your data. The core unit is the component — a reusable, self-contained piece of UI. A page is a tree of components nested like custom HTML tags.

Anatomy of a component

A component is a TypeScript class with a @Component decorator, usually split across three files: the .ts (logic/data), .html (template), and .scss (scoped styles).

@Component({
  selector: 'app-star-rating-display',   // the custom tag: <app-star-rating-display />
  imports: [DecimalPipe, MatIconModule], // standalone: declares its own deps
  templateUrl: './star-rating-display.component.html',
  styleUrl: './star-rating-display.component.scss',
  changeDetection: ChangeDetectionStrategy.OnPush,
})
export class StarRatingDisplayComponent {
  rating = input<number>(0);   // data in, from a parent
  stars = computed(() => { /* which stars to fill */ });
}
  • selector — the tag used to place this component elsewhere. The app- prefix avoids clashing with real HTML.
  • Scoped styles — styleUrl CSS affects only this component, never leaking out. A major Angular feature.
  • Standalone — modern components declare dependencies in imports. You do not write standalone: true; it's the default.

Mental model

Angular is a tree of components. Each keeps its slice of the screen in sync with its data. You declare the relationship (bindings) once; Angular does the updating forever.
