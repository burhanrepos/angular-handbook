Before Angular 14, components couldn't import anything themselves — they were grouped into NgModules. Since v17, standalone is the default.

@NgModule fieldContains
declarationscomponents/directives/pipes this module owns (each in exactly one module)
importsother modules (or standalone items) whose exports it needs
providersservices / DI tokens
exportswhat importers of this module may use

forRoot() vs forChild()

forRoot() — call once at the root; registers a library's global singletons + config (router, store core). forChild()/forFeature() — per feature; registers feature-scoped pieces without recreating singletons.

Providers & multi: true

{ provide: HTTP_INTERCEPTORS, useClass: AuthInterceptor, multi: true }

multi: true means "add to a collection under this token" — that's how the interceptor chain is built.

Standalone bootstrap modern

bootstrapApplication(AppComponent, {
  providers: [
    provideRouter(routes),                              // replaces RouterModule.forRoot
    provideHttpClient(withInterceptors([authInterceptor])), // functional interceptors
    provideAnimations(),
  ],
});
