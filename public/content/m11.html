Content projection lets a component render caller-supplied markup — Angular's equivalent of React children / Web Component <slot>.

// single slot
<div class="card"><ng-content></ng-content></div>

// multi-slot with select
<ng-content select="[slot=header]"></ng-content>
<ng-content select="[slot=end]"></ng-content>

// usage
<app-card><h2 slot="header">Title</h2><p>Body</p></app-card>
TagPurpose
<ng-content>project the caller's content into a slot
<ng-template>markup that isn't rendered until asked (a TemplateRef)
<ng-container>a logical group that renders NO element
// define once, render in multiple places — avoids duplication
<ng-container *ngTemplateOutlet="content"></ng-container>
<ng-template #content><ng-content></ng-content></ng-template>
