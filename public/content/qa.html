AppendixInterview Prep

Popular Interview Questions & Answers

Grouped by topic and ordered roughly junior → senior. Read the question, answer it aloud, then expand to check. Anything marked modern is the current best practice; interviewers love when you can contrast it with the legacy approach.

Core concepts
What is Angular, and how does it differ from a library like React?

Angular is a full, opinionated framework (routing, forms, HTTP, DI, testing all included), built with TypeScript. React is a UI library that leaves those choices to you. Angular uses a component + template + DI architecture and (increasingly) signals for reactivity.

What is a component, and what are its main parts?

A reusable unit of UI: a class with a @Component decorator (metadata: selector, template, styles, change detection), a template (HTML with bindings), and scoped styles. Components form a tree.

Explain the difference between [ ], ( ), and [( )].

[prop] = property/input binding (data in). (event) = event/output binding (event out). [(x)] = two-way binding, sugar for [x]="v" (xChange)="v=$event".

What are standalone components and why do they matter? modern

Components/directives/pipes that declare their own dependencies via imports, with no owning NgModule. Default since v17. Benefits: less boilerplate, better tree-shaking, simpler lazy loading (lazy-load a component or a routes array directly), easier testing.

Interpolation vs property binding — is {{x}} the same as [textContent]="x"?

Nearly. Interpolation coerces to string and concatenates; property binding sets the actual DOM property and can carry any type. Use interpolation for text, property binding for non-string properties and expressions.

Signals & reactivity
What is a signal? How do you read and write one?

A reactive container for a value. Read by calling it: count(). Write with .set(v) or .update(fn). When it changes, Angular re-renders consumers (even zoneless). Never use .mutate().

computed() vs a method vs effect()?

computed() = a memoized derived value; recomputes only when its signal dependencies change. A method runs on every change-detection cycle (avoid in templates). effect() runs a side effect when signals change — use sparingly, not for deriving values.

How do signals relate to RxJS? How do you bridge them?

Signals are synchronous, pull-based, glitch-free state; RxJS models async streams over time. Bridge with toSignal(obs$) and toObservable(sig). Use signals for component state, RxJS for events/async pipelines.

What is input() / output() / model()? modern

Signal-based component I/O. input() (and input.required()) replaces @Input — read as a signal. output() replaces @Output. model() creates a two-way (input + xChange output) writable signal for [(x)] binding.

Directives, templates, pipes
@if/@for/@switch vs *ngIf/*ngFor/*ngSwitch?

The @-blocks are the modern built-in control flow (v17+): faster, better type-narrowing, built into the compiler, with @empty/@else. The *ng* structural directives are legacy but still supported. @for requires track.

Why is track required in @for?

It identifies each item so Angular can reuse/move DOM nodes instead of destroying and recreating the whole list on every change — huge for performance and preserving element state/focus. Use a stable unique id.

Difference between a component, an attribute directive, and a structural directive?

Component = directive with a template. Attribute directive = changes appearance/behaviour of an existing element ([clickOutside]). Structural directive = changes DOM layout by adding/removing elements (*ngIf; the @-blocks now cover this).

Pure vs impure pipe?

A pure pipe (default) recomputes only when its input reference changes — cached, fast. An impure pipe runs every CD cycle (e.g. async). Prefer pure pipes; avoid method calls in templates for the same reason.

ng-content vs ng-template vs ng-container?

ng-content projects caller content into a slot (with select for multi-slot). ng-template defines markup not rendered until asked (a TemplateRef, rendered via ngTemplateOutlet). ng-container is a grouping element that renders no DOM.

Dependency Injection & services
How does Angular's DI work? What is a provider?

A hierarchical injector system resolves dependencies by token. A provider tells the injector how to create a token's value: { provide: TOKEN, useClass/useValue/useFactory/useExisting }. Injectors form a tree (root → route → component); resolution walks up until found.

providedIn: 'root' vs providing in a component?

'root' = a single app-wide singleton (tree-shakable). Providing at a component creates a new instance per component instance and its children — useful for scoped state. Providing in a lazy route scopes to that route.

What does multi: true do?

Registers multiple values under one token as an array instead of overwriting. It's how the HTTP interceptor chain, validators, and app initializers are assembled.

What is an InjectionToken and when do you use one?

A typed token for injecting non-class values (config objects, primitives, functions) or for abstracting a dependency so a generic service doesn't depend on a concrete app class. Combine with @Optional() so code still works when no provider is registered.

RxJS & HTTP
Observable vs Promise?

Promise: single value, eager, not cancellable. Observable: 0..n values over time, lazy (runs on subscribe), cancellable, composable via operators. Angular HTTP returns Observables.

switchMap vs mergeMap vs concatMap vs exhaustMap?

switchMap: cancel previous inner, keep latest (search). mergeMap: run all concurrently (parallel independent calls). concatMap: queue in order (sequential saves). exhaustMap: ignore new while one is running (prevent double-submit, polling).

How do you avoid memory leaks from subscriptions?

Prefer the async pipe (auto-unsubscribes). For manual subscriptions use takeUntilDestroyed(destroyRef) modern, or takeUntil(destroy$) in ngOnDestroy, or the untilDestroyed lib. Operators that complete (like HTTP + first()) also self-clean.

What is an HTTP interceptor and give real uses.

Middleware that transforms every request/response. Uses: attach auth tokens, add tenant/locale headers, global error handling, retry, logging, caching. Modern form is a functional HttpInterceptorFn registered via provideHttpClient(withInterceptors([...])); legacy is a class + HTTP_INTERCEPTORS multi-provider.

How would you build a debounced typeahead?

control.valueChanges.pipe(debounceTime(300), distinctUntilChanged(), switchMap(t => api.search(t))). debounceTime waits for a pause, distinctUntilChanged skips duplicates, switchMap cancels stale requests.

Forms
Reactive vs template-driven forms?

Reactive: model in TS (FormGroup/FormControl), synchronous, testable, scales, good for dynamic/complex forms. Template-driven: model inferred from ngModel directives in HTML, async, simpler for tiny forms. Prefer reactive.

How do you write a custom validator? A cross-field validator?

A function (control) => ValidationErrors | null returning e.g. { invalidX: true } or null. Cross-field validators are placed on the FormGroup and read multiple child controls. Async validators return an Observable/Promise of errors.

What is ControlValueAccessor?

An interface that lets a custom component act as a native form control — implement writeValue, registerOnChange, registerOnTouched, setDisabledState and provide NG_VALUE_ACCESSOR. Then a parent can use [(ngModel)] or formControlName on your component.

Routing
How does lazy loading work and why use it?

loadChildren: () => import('./x').then(m => m.routes) downloads a feature's code only when its route is first visited, shrinking the initial bundle and speeding startup. Standalone lets you lazy-load a single component too.

Types of route guards?

canActivate (enter), canActivateChild (enter children), canMatch/canLoad (match/download a lazy route), canDeactivate (leave — unsaved-changes prompts). Modern guards are functions returning boolean | UrlTree | Observable<...>.

How do you read route params, and snapshot vs observable?

route.snapshot.paramMap.get('id') for a one-time read; route.paramMap.subscribe(...) when the param can change while staying on the same component (Angular reuses it). Same distinction for query params and data.

What is a resolver and a trade-off of using one?

Pre-fetches data before the route activates so the view opens ready. Trade-off: it delays navigation until data arrives (no loading state in-component), so overuse hurts perceived speed; often letting the component fetch with a spinner is better.

State management (NgRx)
When do you actually need NgRx?

When lots of components share and mutate the same state, you need predictable/traceable updates, undo/time-travel, or complex async coordination. For local or simple state, signals/services are enough — don't add NgRx by default.

Explain the NgRx data flow.

Component dispatches an action → reducer (pure) produces new state → store updates → selectors (memoized) emit to components. Side effects (API) run in effects, which listen for actions and dispatch success/failure actions.

Why must reducers be pure and immutable?

Purity makes state changes deterministic, testable, and enables time-travel debugging. Immutability (new references) is what lets OnPush and memoized selectors detect change cheaply by reference comparison.

Why put API calls in effects, not services or components?

Effects centralize side effects and their outcomes (dispatch success/failure, navigate, catch errors) while keeping reducers pure and services thin (services just return Observables). This separation keeps the whole loop predictable.

What does a selector's memoization give you?

It caches the last result and only recomputes when inputs change, avoiding redundant work and unnecessary emissions/re-renders. Selectors also compose, so you derive complex views without recomputing everything.

Change detection & performance
What triggers change detection, and what does OnPush change?

By default (Zone.js) any async event (clicks, timers, HTTP) triggers a full CD pass. OnPush limits a component to re-check only on input reference change, an event within it, an async emission, or a signal read change — letting Angular skip subtrees.

What is Zone.js and what is zoneless CD? modern

Zone.js monkey-patches async APIs so Angular knows when to run CD automatically. Zoneless removes it and drives CD explicitly from signals, the async pipe, and event bindings — smaller bundle, better perf, no over-triggering. Enabled with provideZonelessChangeDetection().

Name five ways to improve Angular performance.

OnPush; track in @for; lazy loading + @defer; pure pipes/computed() over template methods; virtual scrolling; NgOptimizedImage; preloading strategies; avoiding unnecessary subscriptions; bundle budgets and tree-shaking.

What is @defer and its triggers?

A template block that lazy-loads its content and dependencies (auto code-split) with @placeholder/@loading/@error. Triggers: on idle, on viewport, on interaction, on hover, on timer, when cond, and prefetch on ....

Lifecycle & DOM
List the lifecycle hooks in order.

ngOnChanges → ngOnInit → ngDoCheck → ngAfterContentInit → ngAfterContentChecked → ngAfterViewInit → ngAfterViewChecked → ngOnDestroy. Modern: signals/effect and afterNextRender/afterRender reduce the need for several.

Why can't you access a viewChild element in ngOnInit?

The view isn't rendered yet in ngOnInit. View queries resolve by ngAfterViewInit (or read the viewChild() signal after that). DOM measurement/focus belongs there or in afterNextRender.

viewChild vs contentChild?

viewChild queries elements/components in the component's own template. contentChild queries content projected into it via ng-content.

SSR, hydration, i18n
CSR vs SSR vs SSG — when to use each?

CSR for internal apps where SEO/first-paint don't matter. SSR for public, dynamic, SEO-sensitive pages (renders real HTML per request). SSG for content known at build time (docs, marketing) — prerendered static files, fastest and cheapest.

What is hydration, and destructive vs non-destructive?

Hydration is the client app taking over server-rendered DOM. Non-destructive (modern, via provideClientHydration()) reuses the existing DOM — no flicker. Destructive (old) threw it away and re-rendered.

What is incremental hydration and event replay?

Incremental hydration (withIncrementalHydration() + @defer (hydrate on ...)) hydrates blocks lazily on a trigger, deferring their JS. Event replay (withEventReplay()) captures user events during the pre-hydration window and replays them once hydrated.

Top SSR bug: what breaks and how do you fix it?

Using browser globals (window, document, localStorage) on the server crashes it. Guard with isPlatformBrowser(inject(PLATFORM_ID)) or use afterNextRender()/afterRender() (browser-only). Also avoid direct DOM manipulation and invalid HTML that cause hydration mismatches.

Angular built-in i18n vs ngx-translate?

Built-in is compile-time: i18n attribute + $localize, extract with ng extract-i18n, one bundle per locale — best performance/SEO but a rebuild to switch. ngx-translate/Transloco are runtime: JSON dictionaries, switch language live, one bundle — more flexible, slightly heavier.

Security & accessibility
How does Angular protect against XSS?

Contextual auto-sanitization (HTML/style/URL/resource-URL) and always-escaped interpolation. Binding to [innerHTML] is sanitized. You only open a hole by bypassing sanitization (bypassSecurityTrust*) or manipulating the DOM/strings directly.

When is DomSanitizer.bypassSecurityTrustHtml appropriate?

Only for content you fully control/trust (never raw user input). It disables sanitization for that value, so misuse reintroduces XSS. Prefer letting Angular sanitize.

How do you make an Angular app accessible?

Semantic HTML first, ARIA to fill gaps; WCAG AA contrast; visible focus; full keyboard support; focus management for dialogs/menus (CDK FocusTrap, LiveAnnouncer); announce dynamic changes with aria-live; test with axe, keyboard, and a screen reader.

Architecture & senior-level
NgModule vs standalone — how would you migrate?

Standalone removes NgModules; components import their own deps and the app bootstraps via bootstrapApplication + provideX(). Migrate incrementally (they interop): convert leaf components first with the CLI schematic, replace SomeModule.forRoot() with providers, then drop modules. A hybrid app is normal mid-migration.

How do you decide between signals, RxJS, and NgRx for state?

Signals for local/component and simple shared state (via a service). RxJS for async streams and event orchestration. NgRx for large, cross-cutting, shared state needing traceability and structure. Use the lightest tool that fits; combine them (e.g. signals + toObservable).

What makes a service well-designed?

Single responsibility; returns Observables rather than subscribing; doesn't inject UI concerns (MatDialog/Router/Store) unless that's its job; depends on abstractions (InjectionToken) not concrete app classes; reference-counted loading state; no dead/legacy public API.

How does the CLI help with upgrades and consistency?

ng update runs automated migration schematics for breaking changes across versions; ng generate scaffolds consistent artifacts; lint + budgets enforce standards; DevTools and the Language Service catch issues early. Staying current keeps the app fast and secure.

Explain the OnPush + immutability + signals connection.

They're one system. OnPush detects change by reference or signal notification. Immutable updates (NgRx ...spread) and signal writes both produce those signals, so the UI updates correctly and cheaply. Mutating in place under OnPush is the classic "why isn't my view updating?" bug.
