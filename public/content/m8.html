A pipe transforms a value for display without changing the underlying data: {{ value | pipeName:arg }}.

@Pipe({ name: 'fileSize' })          // standalone by default
export class FileSizePipe implements PipeTransform {
  transform(value: number): string {
    const kb = value / 1024;
    return kb > 1024 ? `${(kb/1024).toFixed(1)} MB` : `${Math.round(kb)} KB`;
  }
}

Built-ins you'll use: date, number, currency, uppercase, json, slice, async. Chain with |, pass args with :.

Pure vs impure

A pure pipe (default) recomputes only when its input reference changes — cached and fast. An impure pipe (pure: false) runs every change-detection cycle (the async pipe is impure). Prefer pure pipes; this is why the codebase forbids method calls in templates.
